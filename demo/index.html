Glottal source

Teach a word

See how a word is pronounced, or correct it in ARPAbet. A digit after a vowel sets its stress: 1 main, 2 secondary, 0 none.

Words it gets wrong

Full pronouncing dictionary

About 50,000 common words are covered out of the box. Loading the 134,000-word CMU dictionary adds rare names and jargon; it is fetched from GitHub.

Using the built-in lexicon and letter-to-sound rules.

Voice file

A voice is only its settings. Save it as JSON, share it, or load one fitted to a speaker with tools/fit_voice.py.

Use it from code

tts.wasm has no imports and carries its own JavaScript wrapper, so one file is the whole engine. The snippet follows what is in the composer.



          

            
Script and score reference

          

          

            
Voices

            
[male] [female] [bright] [deep] [husky] [whisper] [woman_a] [woman_b] [man_a] [man_b] [soprano] [alto] [tenor]

            
Your own

            
v.randomize({ name: "hero", gender: "female" }) then [hero]

            
Delivery

            
[excited] [calm] [happy] [sad] [speed=1.2] [pitch=+3st] [reset]; laughing while speaking: [laughing] … [/laughing], [laughter=0.8], or the laughter setting

            
Timing

            
[pause=300ms] [inhale]

            
Sounds

            
[laugh] [giggle] [chuckle] [sigh] [gasp] [cough] [hmm] [uh-huh] [shh] [whistle] and the rest of TTS.sounds(); stronger or longer with [laugh=strong], [sigh length=1.5], for a set time with [laugh=3s]; from code, v.sound("laugh", { durationMs: 3000 })

            
Singing

            
C4:1=Twin- G4:2=star R:1 rest, ~ hold; v.sing(notes, lyrics, bpm), v.singChorus({ bpm, parts })
